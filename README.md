# Breathe Strong website

Static site for GitHub Pages, served at `/breathe-strong-site/`. No build step.

- `index.html`: homepage
- `about.html`: privacy, medical disclaimer, tester limitations, contact, about
- `program.html`: redirect to the homepage (old address)
- `site.css`: shared styles
- `img/`: app screenshots and exercise illustrations taken from the tester app

All links and asset paths are relative. Search for `TODO` in `about.html` for owner details still needed.
